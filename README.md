# Тренажёр C#

Локальный сайт для практики по книге Майка МакГрата «C# для начинающих». В нём 12 глав, упражнения, тесты, таймер занятий и журнал решений. Сервер на Python выполняет учебные программы через установленный .NET SDK.

## Запуск

Установите Python 3 и .NET SDK. В Windows запустите start.bat или выполните python server.py и откройте http://127.0.0.1:8777. Прогресс и отправленные решения сохраняются локально. Команда python pending.py показывает решения, ожидающие проверки.
